## 계약별 화면 기획 — 2026-11-11

- 메뉴명은 **회사별 → 계약별로 구분**으로 변경합니다.
- 계약 하나당 한 줄이며 같은 보험회사의 서로 다른 계약도 구분합니다.
- 목록은 **보험회사명 / 보험상품명 / 보험료 / 상세보기** 표로 표시합니다.
- 보험료는 **매달 실제 납부하는 금액**이며 `월 ○○원`으로 표시합니다. 보장 가입금액과 구분합니다.
- 상세보기는 기존 **내보험보기**처럼 해당 계약을 하나의 증권 형태로 보여줍니다.
- 상단에는 보험회사·상품명·월 보험료·계약기간·납입기간을 표시합니다.
- 아래에는 해당 상품의 **모든 보장과 특약을 빠짐없이** 표시합니다.
- 보장 표의 열은 **보장명·특약명 / 보장내용 / 가입금액 / 보장기간**입니다.
- PC와 모바일에서 동일한 계약 정보와 전체 보장내역을 확인합니다.
