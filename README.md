**제출용 공개(Public) 저장소:** https://github.com/blue592/hidden-insurance-manager

## 데이터 보존 원칙

- 기존 HTML·백업·코드 저장소·브라우저 DB를 덮어쓰지 않습니다.
- 가져온 원본과 수정 내역을 분리하고, 사용하지 않는 필드도 보존합니다.
- 계약·보장·문서의 연결 ID와 원문 근거를 유지합니다.
- 기획서 변경만으로 사용자 데이터를 변환하지 않습니다.
- 업데이트와 데이터 형식 변경은 사본 검증·백업 왕복·복구 확인 후 적용합니다.
- 실제 증권·약관·개인정보 JSON·백업은 커밋하지 않습니다.

미션 완료 여부는 이후 실제 제작 결과·검증 기록과 수업의 제출 기준을 대조해 판단합니다. 공개 설정만으로 미션 완료로 처리하지 않습니다.
